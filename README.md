# THE LU DECOMPOSITION

> A sphere of **UD0** — the ROOT0 universe / biosphere. Domain: **MÉTHODOS**.

THE LU DECOMPOSITION &mdash; a member of [[methodos]]. Factor A=LU (unit-lower L of the elimination multipliers &times; upper U) &mdash; [[the-gaussian-elimination|Gaussian elimination]] made reusable. Factor once O(n&sup3;); then every solve for a new b is a forward + back sweep, only O(n&sup2;) (also gives det = &prod;u&#7522;&#7522; and the inverse). Partial pivoting gives PA=LU. The standard dense direct solver (LAPACK). &#9670; LIT: a fail-loud check throws unless L&middot;U reproduces A. &#9650; AMBER: needs pivoting for stability; dense O(n&sup3;) is costly for huge sparse A.
